# OpenSpec facts — verified against the real CLI

**Version:** `@fission-ai/openspec@2.2.0` (installed with `npm i`; Node v22.23.5, Linux).
**Date:** 2026-11-26 (first written 2026-10-03 against 1.13.0, re-run 2026-10-25 against 1.15.0).
**Method:** each fact was checked in a throwaway project (`git init` + `openspec init --tools claude --scope project`,
or the `checks-good` fixture with the kit copied in) using an isolated config dir (`XDG_CONFIG_HOME=<scratch>`, or the
kit's `openspec/tooling/xdg` for the kit profile), an empty temporary `HOME` with `XDG_DATA_HOME` and
`XDG_STATE_HOME` inside it, and `OPENSPEC_TELEMETRY=0`. Where the behaviour needed explaining, the CLI source in
`dist/` was also read; the file is named in the Evidence column. On 2026-11-26 sections 1–8 were re-run on 2.2.0:
every row of these sections holds the 2.2.0 result unless it is marked *(not re-run)*, and *(changed in 2.2.0)*
marks a result different from 1.15.0.

Status legend: **VERIFIED**, **REFUTED** (the claim from CLAUDE.md or the docs is wrong for the pinned version),
**PARTLY** (true with caveats).

Pristine copy of the built-in schema: `fixtures/upstream/spec-driven-2.2.0/`
(`schema.yaml` sha256 `70ddfd2c…7aa3`; the copy and the package's `schemas/spec-driven/` are byte-equal).

Facts were collected while building 0.1.0. Decision numbers `D<n>` and the `fixtures/dry-runs/phase*`
evidence files refer to the `archive/v0.1` branch. Facts about parts removed in 0.2.0 (pytest/Playwright
runners, the Stop hook, API handoff, generated CI, monorepo, stores) were dropped from this file.
