# OpenSpec 1.15.0 layout

The `.claude/` files that `openspec init --tools claude --no-animation` of OpenSpec 1.15.0 wrote with the kit
profile of kit 0.7.0 (`delivery: both`): the eight skills as folders in `.claude/skills/openspec-*/` and the
eight generated command files in `.claude/commands/opsx/`, unedited. `tests/openspec-cli-install.test.mjs` lays
them over a project to update it with OpenSpec 2.2.0, which recognises them as generated by a released version.
