Teams that hand a vague client request straight to an AI agent get code that does what the agent guessed.
That means bugs for manual QA and rework. **sdd-kit** puts a checked process around OpenSpec and Claude Code:
the agent asks before it plans, every statement has a source, and every scenario has a test that proves it.

## The flow in one line

```text
questions → proposal → specs → design → verification plan → tasks
  → apply (TDD) → test review → full suite → archive
```

You answer questions at the start and archive at the end. Between them the agent plans and implements by itself
and stops only for decisions that belong to you.
